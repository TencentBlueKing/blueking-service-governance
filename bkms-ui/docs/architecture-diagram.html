开发定位指南 — 视图层

  • • 新增页面 → src/pages/{模块}/xxx.vue
  • • 路由注册 → src/modules/router.ts
  • • 菜单配置 → src/config/navigation/{模块}.ts
  • • 布局指定 → route.meta.layout
  • • 动态子页 → CustomRouterComponent
  • • 页面组件 → pages/{模块}/components/

开发定位指南 — 状态/逻辑

  • • 全局状态 → src/stores/xxx.ts
  • • 复用逻辑 → src/composables/use-xxx.ts
  • • 页面级逻辑 → pages/{模块}/use-xxx.ts
  • • 持久化 → pinia.ts（当前存在跨 Store 覆盖风险）
  • • 常量/枚举 → src/common/const.ts / enums/

开发定位指南 — API 层

  • • 新增接口 → src/api/modules/v1/xxx.ts
  • • 使用 v1Fetch.get/post/put/delete
  • • URL {var} 自动替换参数
  • • 错误处理 → fetch.ts 统一注册和处理
  • • 流式/下载 → config.originalResponse
  • • 上传 → config.multipart

开发定位指南 — 组件/构建

  • • 通用组件 → src/components/xxx.vue
  • • 自动导入 · 无需 import
  • • 全局指令 → src/directives/ → global.ts
  • • 样式 → UnoCSS 原子类 + styles/
  • • SVG → src/assets/ → 组件方式导入
  • • License header → 从同类文件复制
