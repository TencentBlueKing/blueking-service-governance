# Mongo 索引汇总

- bkci_projects 新建索引：
  - id_1: BKCI ProjectStoreMongo：项目 ID 唯一；
  - code_1: BKCI ProjectStoreMongo：项目 Code 唯一；
  - workspaceID_1: BKCI ProjectStoreMongo：每个 Workspace 只能有一个蓝盾项目；
- bkci_pipeline_templates 新建索引：
  - id_1: BKCI DBPipelineTemplateStore：模板 ID 唯一；
  - type_1: BKCI DBPipelineTemplateStore：模板 Type 全局唯一；
- bkci_pipelines 新建索引：
  - id_1: BKCI PipelineStoreMongo：流水线 ID 唯一；
  - workspaceID_1_type_1: BKCI PipelineStoreMongo：同一个 Workspace 下流水线 Type 唯一；
- bkci_repositories 新建索引：
  - id_1_projectCode_1: BKCI RepositoryStoreMongo：代码库 ID（hashID）在项目下唯一；
  - workspaceID_1_alias_1: BKCI RepositoryStoreMongo：同一个 Workspace 下仓库 Alias 唯一；
- iam_grade_managers 新建索引：
  - workspaceID_1: IAM RoleStoreMongo：每个 workspace 仅一个分级管理员；
- iam_roles 新建索引：
  - id_1: IAM RoleStoreMongo：角色 ID 业务唯一；
  - workspaceID_1_userGroupID_1: IAM RoleStoreMongo：按 workspaceID + userGroupID 加速删除和列表查询；
- bkrepo_projects 新建索引：
  - id_1: BKRepo ProjectStoreMongo：项目 ID 唯一；
  - workspaceID_1: BKRepo ProjectStoreMongo：每个工作空间只会有一个蓝盾制品库项目；
- bkrepo_repositories 新建索引：
  - workspaceID_1_type_1: BKRepo RepositoryStoreMongo：每个工作空间的每种类型只会有一个仓库；
- build_auto_deploy_records 新建索引：
  - appID_1_buildID_1: Build Auto Deploy RecordStoreMongo：appID + buildID 唯一；
  - appID_1_envName_1_trafficLaneName_1_createdAt_-1: Build Auto Deploy RecordStoreMongo：按 appID + envName + trafficLaneName 查询时支持按 createdAt 倒序读取；
  - appID_1_deployID_1: Build Auto Deploy RecordStoreMongo：仅对 deployID 非空记录约束 appID + deployID 唯一；原始代码注明 Mongo 部分索引不支持 $ne，所以用 $gt 代替；
- helm_chart_build_records 新建索引：
  - appID_1_buildID_1: Helm Chart RecordStoreMongo：appID + buildID 唯一；
- build_configs 新建索引：
  - appID_1: Build ConfigStoreMongo：给 build_configs 创建索引，appID 唯一；
- build_records 新建索引：
  - appID_1_buildID_1: Build RecordStoreMongo：appID + buildID 唯一；
- app_config_files 新建索引：
  - appID_1_name_1: AppConfigFileStoreMongo：按代码实际键定义 appID + name 唯一；
  - baseAppConfigFileID_1: AppConfigFileStoreMongo：baseAppConfigFileID 查询索引；
- app_config_file_versions 新建索引：
  - appConfigFileID_1_version_1: AppConfigFileVersionStoreMongo：同一配置文件内 version 唯一；
  - appConfigFileID_1_isDeleted_1_createdAt_-1: AppConfigFileVersionStoreMongo：按 appConfigFileID / isDeleted 列表查询时支持 createdAt 倒序；
  - appID_1_envName_1_isDeleted_1_createdAt_-1: AppConfigFileVersionStoreMongo：按 appID / envName / isDeleted 列表查询时支持 createdAt 倒序；
  - appConfigFileID_1_isDeleted_1_creator_1_createdAt_-1: AppConfigFileVersionStoreMongo：按 appConfigFileID / isDeleted / creator 过滤时支持 createdAt 倒序；
- applications 新建索引：
  - id_1: ApplicationStoreMongo：应用 ID 唯一；
  - workspaceID_1_name_1: ApplicationStoreMongo：同一 workspace 下应用名唯一；
- cluster_addon_defs 新建索引：
  - name_1: ClusterAddonDefStoreMongo：Addon name 唯一；
- environments 新建索引：
  - workspaceID_1_name_1: EnvironmentStoreMongo：同一 workspace 下环境名唯一；
  - ownerAppID_1: EnvironmentStoreMongo：按 ownerAppID 查询 feature 环境时使用；
- workspace_components 新建索引：
  - workspaceID_1_name_1: WorkspaceCompsStoreMongo：同一 workspace 下组件名唯一；
- workspaces 新建索引：
  - id_1: WorkspaceStoreMongo：工作空间 ID 唯一；
- app_model_resource_snapshots 新建索引：
  - appID_1_deployRecordId_1: Deploy AppModel ResourceSnapshotStoreMongo：按 appID + deployRecordId 快速查询某次部署下的全部快照；
- gpa_configs 新建索引：
  - appID_1_envName_1: GPAConfigStoreMongo：每个应用 + 环境唯一一份 GPA 配置；
- polaris_configs 新建索引：
  - appID_1_name_1: PolarisConfigStoreMongo：appID + name 唯一；
- bscpcfg_env_bindings 新建索引：
  - appID_1_envName_1: EnvBindingStoreMongo：appID + envName 唯一；
- bscpcfg_metadata 新建索引：
  - appID_1: MetadataStoreMongo：appID 唯一；
- helm_app_components 新建索引：
  - appID_1_envName_1_name_1: DbHelmAppComponentStore：同一应用同一环境下组件名不能重复；
  - appID_1_envName_1: DbHelmAppComponentStore：按应用 + 环境查询组件引用；
- component_defs 新建索引：
  - name_1_version_1: ComponentDefStoreMongo：组件定义 name + version 唯一；
- depservice_instances 新建索引：
  - workspaceID_1_serviceName_1_name_1: ServiceInstanceStoreMongo：同一 workspace / serviceName 下实例名唯一；
- depservice_services 新建索引：
  - name_1: ServiceStoreMongo：服务 name 唯一；
- depservice_bindings 见 `000005_depservice_bindings_idx.md`。
- operation_records 新建索引：
  - username_1_group.workspaceID_1_createdAt_-1: OperationRecordStoreMongo：覆盖按用户 + workspace 维度的聚合查询及列表查询；
  - username_1_group.workspaceID_1_group.appID_1_createdAt_-1: OperationRecordStoreMongo：覆盖按用户 + workspace + app 维度的聚合查询；
- bkmonitor_alert_strategy 新建索引：
  - workspaceID_1_appID_1_enabled_1: AlertStrategyStoreMongo.ListEnabledByAppMatchingEnv 按 workspaceID + appID + enabled 过滤已启用策略；
  - workspaceID_1_appID_1_remoteRefs.envID_1_remoteRefs.trafficLaneName_1: AlertStrategyStoreMongo.ListByAppAndRemoteEnv 按 workspaceID + appID + remoteRefs 环境/泳道 $elemMatch 查询（multikey 索引）；
- bkmonitor_apm_inst_config 新建索引：
  - apmID_1: ApmInstConfigStoreMongo：apmID 唯一；
- plat_admin_role_bindings 新建索引：
  - username_1: Platform Admin StoreMongo：username 唯一；
- workspace_temp_admin_records 新建索引：
  - workspaceID_1_username_1: Workspace Temp Admin StoreMongo：仅对 isRecycled = false 的活跃授权约束 workspaceID + username 唯一；
  - isRecycled_1_expiresAt_1: Workspace Temp Admin StoreMongo：列出待清理的已过期且未回收记录；
- app_models 新建索引：
  - appID_1: AppModelStoreMongo：appID 唯一；
- app_specs 新建索引：
  - appID_1_envName_1: AppSpecStoreMongo：appID + envName 唯一；
- scoped_env_vars 新建索引：
  - workspaceID_1_scopeType_1_scopeValue_1_key_1: ScopedEnvVarStoreMongo：同一 workspace / scopeType / scopeValue 下 env var key 唯一；
- helm_repo_credentials 新建索引：
  - workspaceID_1: HelmRepoCredentialStoreMongo：每个工作空间一条 Helm 仓库凭证记录；
- image_promotions 新建索引：
  - idx_appID_repoKey_tag: PromotionStoreMongo：镜像晋级记录以 appID + repoKey + tag 幂等 upsert，要求唯一；
- image_registries 新建索引：

- runtime_images 新建索引：

- image_snapshots 新建索引：
  - idx_repoKey_tag: SnapshotStoreMongo：镜像快照 repoKey + tag 唯一；
  - idx_repoKey: SnapshotStoreMongo：按 repoKey 查询镜像快照；
- repo_snapshot_statuses 新建索引：
  - idx_repoKey: SnapshotStoreMongo：仓库快照状态 repoKey 唯一；
- networking_services 新建索引：
  - appID_1_name_1: Networking ServiceStoreMongo：appID + name 唯一；
- topology_resource_snapshots 新建索引：
  - appID_1_envName_1_trafficLaneName_1: Topology ResourceSnapshotStoreMongo：appID + envName + trafficLaneName 唯一；
  - appID_1: Topology ResourceSnapshotStoreMongo：支持按应用快速查询；
